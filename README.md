# About
A really small, compact and simple USB-C PCB with 2 output pads and of course USB-C (16pin). It's for 12V (47k resistor), but if you want higher voltage, buy a different resistor.

# features
USB-C 16 pin, 2 output pads, 2 resistors, 1 poly fuse, CH221K for higher voltage, 1uf capacitor and 30uf capacitor.
