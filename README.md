# About
A really small, compact and simple USB-C PCB with 2 output pads and of course USB-C (16pin). It's for 12V (47k resistor), but if you want higher voltage, buy a different resistor and fuse.

# features
USB-C 16 pin, 2 output pads, 2 resistors, 1 poly fuse, CH221K for higher voltage, 1uf capacitor and 30uf capacitor.

# dimensions
PCB - 22.75 mm x 10.75 mm

# why did I create it
I wanted a way to convert my soldering iron to USB-C for better usability, so I thought why not make it for more use and for more people, so that's how it was created.
